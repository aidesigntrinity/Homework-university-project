ManageBac

This page cannot reach ManageBac by itself, so it works from your ManageBac calendar link. Two ways to bring it in:

1 · Import a calendar file
  1. In ManageBac open My Workspace, then View Full Calendar, then Subscribe to Calendar, and copy the link.
  2. If it starts with webcal://, change that part to https://, then open it in a new browser tab.
  3. A file ending in .ics should download. Drop it below. If text shows instead, copy it all and paste it in the box.
Drop the .ics file here or tap to choose it

Keep that link private. Anyone who has it can read your calendar. Menu names vary a little between schools.
2 · Auto-sync with a free relay Paste the address of your sync relay (set up below). Due Board then fetches your deadlines when it opens and every 15 minutes while it stays open.
How to set up the relay (free, about 10 minutes)
  1. Go to script.google.com, sign in, and choose New project.
  2. Delete the sample code and paste the code below. Replace the two values at the top: your ManageBac calendar link, and a long made-up phrase as your key.
  3. Choose Deploy, then New deployment, type Web app. Set Execute as to Me and Who has access to Anyone. Deploy, and approve Google's permission screens (for your own script: Advanced, then Go to the project).
  4. Copy the Web app URL, add ?key= and your phrase to the end, and paste it in the box above.
// Due Board sync relay. Your ManageBac link stays inside your own Google account.
var CALENDAR_LINK = "PASTE YOUR MANAGEBAC CALENDAR LINK HERE";
var SECRET_KEY = "MAKE-UP-A-LONG-RANDOM-PHRASE";

function doGet(e) {
  if (!e.parameter.key || e.parameter.key !== SECRET_KEY) {
    return ContentService.createTextOutput("Wrong or missing key");
  }
  var cache = CacheService.getScriptCache();
  var ics = cache.get("ics");
  if (!ics) {
    ics = UrlFetchApp.fetch(CALENDAR_LINK.replace(/^webcal:/i, "https:")).getContentText();
    if (ics.length < 90000) cache.put("ics", ics, 300);
  }
  return ContentService.createTextOutput(ics);
}
Keep the web app address private: with the key, it returns your calendar. This works on the public website and in the downloaded Due-Board.html file, but not inside the Claude page, which blocks outside connections.

Google Calendar

Three free ways to get your homework into Google Calendar, where alerts and email reminders are built in:

  1. One task: open a task and use Add to Google Calendar. It opens Google Calendar with the due time filled in; press Save there.
  2. Everything upcoming: download the file below, then in Google Calendar choose Settings, Import & export, and import it.
  3. Straight from ManageBac: in Google Calendar, add your ManageBac link under Other calendars, From URL. It stays in sync by itself (slowly), no app needed.
In your calendar's notification settings, add an Email notification (for example 1 day before) to get reminders by mail. Importing twice lists items twice, so remove the earlier ones first.
