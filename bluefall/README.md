# Bluefall

A 3D endless downhill ball-rolling game in one HTML file (three.js), with a VHS / neon synthwave look and a soundtrack generated live in the browser.

- **Play:** open `game/bluefall.html` in a browser (needs internet the first time, for fonts and the 3D library).
- **Edit:** `game/bluefall-source.html` is the same game without the `<html>/<head>` wrapper.
- **Soundtrack:** `songs/` holds the built-in songs rendered to MP3, plus "Deep Space Drive", an original long-form track.
- **Project notes:** `CONTINUE_HERE.md` describes every feature, how the code is organised and how to keep working on it.
- **Re-rendering songs:** see `CONTINUE_HERE.md`; the tools are in `tools/` (`render.js` renders the game songs, `render_one.js` renders a single song).

All music in this folder is original and made with the game's own sound engine.
